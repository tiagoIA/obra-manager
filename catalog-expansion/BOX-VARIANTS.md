# Box variants and material filters

Published and verified on 2026-10-16. Added 51 identified manufacturer/model records, enriched missing technical fields on 337 existing products, and corrected 19 box classifications. Read-back confirmed 3,339 active catalog records and 479 boxes/accessories; 138 records have declared capacity and 102 have depth. Unknown specifications remain blank. Existing quantities, purchase history, pricing, and user-entered technical values were preserved.

Box fields cover width, height, depth, capacity in cubic inches, gangs, material, shape, work type, knockouts, mounting, application and indoor/outdoor use. Capacity is never calculated from outer dimensions. Thirty exact source sheets and literal public retailer product titles supplied the recorded attributes; per-field evidence retains which source supplied each value. Supplier images remain external references, with an optional second image. Unidentified manufacturers were excluded.

Other materials now offer family-specific filters for wire/cable type and conductor material; fitting connection type and material; conduit/support material and length; and lighting diameter, actual wattage when unambiguous, lumens, and color temperature. Browsing fallbacks read explicit product labels and do not save inferred compatibility or technical ratings. Structured manual entries persist through the live application adapter.

Native data/identity checks and mobile/desktop browser tests passed before import and publication. Box browser coverage includes volume/depth filtering, displayed specifications, edited field persistence, preservation of quantities/history, and mobile overflow checks. Hosting source hashes were verified in preview and live. Details are in `box-completion.json`; import inputs are `box-products.json` and `box-manifest.json`.
